# نمایش تصاویر دیالوگ پس از دیپلوی

اگر تصویر دیالوگ در محیط توسعه دیده می‌شود ولی پس از بیلد ناپدید می‌شود، مقدار
`background-image` را در ابزار توسعهٔ مرورگر بررسی کنید. بیلد ممکن است تصاویر کوچک
SVG را به آدرس `data:` تبدیل کند؛ کوتیشن‌های داخل این آدرس باعث نامعتبر شدن
`url(...)` بدون کوتیشن می‌شوند.

برای پس‌زمینه‌های پویا از تابع مشترک `cssUrl` استفاده کنید. پس از دریافت اصلاح،
ایمیج‌های پنل کاربر و ادمین را مجدداً بیلد و دیپلوی کنید و صفحه را بازخوانی کنید.
نمایش تصویر در فرم افزودن کاربر، تیم، تخصیص اپراتور و گزارش زمان‌بندی‌شده را بررسی کنید.
اگر مشکل باقی ماند، وضعیت درخواست تصویر و خطاهای کنسول مرورگر را بررسی کنید.

تست `cssUrl.test.mjs` یک SVG واقعی را با Vite بیلد می‌کند تا آدرس تولیدی در
پس‌زمینهٔ CSS به‌درستی داخل کوتیشن قرار بگیرد و این مشکل تکرار نشود.
