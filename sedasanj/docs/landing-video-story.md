# ویدئوی صفحه اصلی (پنل استوری «چرا صداسنج؟»)

همه‌چیز از پنل ادمین، بخش **صفحه‌های سایت ← ویدئوی صفحه اصلی** مدیریت می‌شود و بدون تغییر کد
منتشر می‌شود (`PUT /v1/admin/site-pages/landing_video`، ذخیره در `platform_settings`).

## رفتار برای بازدیدکننده

- دکمه شناور «چرا صداسنج؟» (پایین صفحه) و دکمه پخش بالای صفحه اصلی، هر دو پنل را باز می‌کنند.
  تا وقتی «ویدئوی اصلی» بارگذاری نشده باشد، هیچ‌کدام نمایش داده نمی‌شوند.
- پنل در گوشه پایین صفحه باز می‌شود (سمت راست یا چپ، قابل انتخاب)، ویدئوی اصلی پخش می‌شود و
  روی آن سؤال‌ها دیده می‌شوند. کلیک روی ویدئو آن را متوقف یا ادامه می‌دهد.
- کلیک روی هر سؤال، ویدئوی پاسخ همان سؤال را پخش می‌کند و سؤال از فهرست کنار می‌رود.
  دکمه خانه به ویدئوی اصلی برمی‌گردد.
- بعد از پایان آخرین پاسخ (یا ویدئوی اصلی، اگر سؤالی تعریف نشده)، دکمه پایانی و شماره تلفن
  نمایش داده می‌شود. بدون متن/پیوند و بدون تلفن، به‌جای آن‌ها فقط «پخش دوباره» می‌آید.

## تنظیمات

| فیلد | توضیح |
| --- | --- |
| متن دکمه شناور | خالی = «چرا صداسنج؟» |
| آواتار | GIF یا تصویر؛ کنار دکمه شناور و پشت دکمه پخش. اختیاری |
| ویدئوی اصلی | MP4 یا WebM، حداکثر ۱۲۰ مگابایت |
| پخش خودکار | پخش ویدئوی اصلی هنگام باز شدن پنل |
| جای پنل | گوشه پایین سمت راست یا چپ |
| سؤال‌ها | تا ۸ مورد؛ هر مورد هم متن سؤال و هم ویدئوی پاسخ لازم دارد |
| دکمه پایانی | متن + پیوند (`/مسیر`، `https://`، `tel:` یا `mailto:`)؛ خالی = نمایش داده نشود |
| تلفن پایانی | متن کنار شماره + شماره (فقط رقم، `+`، فاصله و خط تیره) |

## خطاها و راه‌حل

- `invalid_request` با مسیر فیلد (مثلاً `questions.1.video_media_id`): ویدئو باید از همین
  بخش بارگذاری شده باشد و نوع فایل ویدئو باشد (آواتار: تصویر). فایل را دوباره بارگذاری و انتخاب کنید.
- «a question needs both its text and its answer video»: سؤال ناقص را کامل یا حذف کنید.
- ویدئو در Safari/iOS پخش نمی‌شود: مسیر `/v1/help/media/<id>` باید `Range` را پشتیبانی کند
  (پاسخ `206`)؛ اگر پشت پراکسی است، هدر `Range` را حذف نکند.
