# تعداد نمایش جدول‌ها

برای باز کردن گزینه‌ها روی دکمهٔ «تعداد نمایش» کلیک کنید؛ متن، عدد و فلش همگی جزو همان دکمه هستند. یکی از مقدارهای ۱۰، ۲۵، ۵۰، ۱۰۰ یا ۲۰۰ را انتخاب کنید. انتخاب جدید صفحه‌بندی را به ابتدا برمی‌گرداند و فیلترها را حفظ می‌کند.

منو در فضای آزاد بالای دکمه یا زیر آن باز می‌شود و داخل جدول بریده نمی‌شود. با کلیدهای جهت‌دار میان گزینه‌ها حرکت کنید، با Enter انتخاب کنید و با Escape یا کلیک بیرون منو را ببندید.

انتخاب در مرورگر برای همان صفحه ذخیره می‌شود و با پارامتر `page_size` در آدرس باقی می‌ماند. پس از بارگذاری دوباره باید همان مقدار دیده شود. اگر ذخیره‌سازی مرورگر مسدود است، آدرس دارای این پارامتر را نشانک بزنید.

اگر گزینه‌ها باز نشدند، صفحه را دوباره بارگذاری کنید تا نسخهٔ جدید رابط دریافت شود. در صورت ادامهٔ مشکل، نام صفحه و مرورگر را برای پشتیبانی ارسال کنید. درخواست مستقیم API با تعداد خارج از بازهٔ مجاز همچنان کد `invalid_request` دارد؛ مقدار را از گزینه‌های منو انتخاب کنید.
