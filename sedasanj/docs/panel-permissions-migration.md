# خطای تأیید پیامک پس از تغییر دسترسی کاربران

اگر تأیید پیامک با خطای سرور روبه‌رو شد و لاگ نبودن ستون `users.panel_permissions` را نشان داد، ساختار دیتابیس با مدل جدید کاربران هماهنگ نیست.

پس از تهیه و بررسی نسخهٔ پشتیبان دیتابیس، از پوشهٔ `sedasanj` و با تنظیم اتصال همان محیط، دستور زیر را اجرا کنید:

```bash
uv run alembic -c apps/api/alembic.ini upgrade head
```

در نصب‌های دارای دیتابیس مجزای سازمان، ساختار دیتابیس‌های سازمانی نیز باید به نسخهٔ جاری ارتقا پیدا کند؛ همگام‌سازی هویت کاربران از همین ستون استفاده می‌کند.

نسخهٔ `0112_user_panel_permissions` ستون اختیاری را اضافه می‌کند. مقدار حساب‌های قبلی خالی می‌ماند تا دسترسی پیش‌فرض نقش حفظ شود؛ فهرست خالی به معنای نداشتن دسترسی انتخابی است و جایگزین مقدار خالی ستون نمی‌شود.

پس از ارتقا، نسخهٔ migration و وجود ستون را بررسی کنید و کد پیامک را دوباره وارد کنید. برای جلوگیری از تکرار، migrationها را پیش از اجرای کد جدید اعمال کنید؛ بارگذاری مجدد خودکار API، migration اجرا نمی‌کند.
