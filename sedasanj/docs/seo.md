# سئوی صفحات عمومی صداسنج

همهٔ متادیتای سئو **هاردکد** است و فقط در یک فایل نگهداری می‌شود: `web/client/src/seo/siteSeo.ts`.
همان فایل خروجی `index.html` هر صفحه، `robots.txt`، `sitemap.xml` و تگ‌های زندهٔ مرورگر را می‌سازد.

## جریان کار

| لایه | چه می‌کند |
| --- | --- |
| `siteSeo.ts` | عنوان، توضیحات، کلیدواژه‌ها، JSON-LD، robots و sitemap هر مسیر |
| `seo/vitePlugin.ts` | هنگام build در `dist/<route>/index.html` همان head را پیش‌رندر می‌کند (برای خزنده‌ها و پیش‌نمایش لینک در تلگرام/واتساپ که JS اجرا نمی‌کنند) |
| `seo/RouteSeo.tsx` | هنگام جابه‌جایی داخل SPA عنوان و تگ‌ها را به‌روز می‌کند؛ صفحات پنل `noindex` می‌شوند |
| `deploy/web-server.mjs` | `/sitemap.xml` زنده (مسیرهای ثابت + مقالات منتشرشدهٔ راهنما)، متای هر مقاله، هدر `X-Robots-Tag` برای پنل، ریدایرکت ۳۰۱ اسلش آخر، وضعیت ۴۰۴ برای مقالهٔ ناموجود |

## دامنهٔ کانونی

دامنهٔ canonical از متغیر build با نام `SITE_URL` می‌آید (پیش‌فرض `https://sedasanj.ir`).
در `compose.yml` اگر `SITE_URL` تعریف نشده باشد از `https://$APP_DOMAIN` استفاده می‌شود.
اگر سایت عمومی روی دامنهٔ دیگری است، `SITE_URL` را در `deploy/.env` بگذارید و کانتینر `client` را دوباره build کنید.

## افزودن یا ویرایش صفحه

1. یک آیتم به `SEO_ROUTES` اضافه کنید (عنوان ۲۰–۷۵ نویسه، توضیحات ۱۰۰–۲۰۰ نویسه، دست‌کم ۵ کلیدواژه، `lastmod`).
2. هنگام تغییر واقعی محتوای صفحه، `lastmod` را به‌روز کنید.
3. مسیر خصوصی جدید پنل را به `PRIVATE_PATHS` اضافه کنید (در `robots.txt` هم می‌آید).
4. `npm run test:unit` را اجرا کنید؛ یکتایی عنوان/توضیحات و قالب JSON-LD بررسی می‌شود.

## راهبرد کلیدواژه

- **هستهٔ صفحهٔ اصلی (قصد تجاری):** تحلیل مکالمات فارسی، تحلیل تماس تلفنی، سنجش کیفیت تماس، ارزیابی کیفیت اپراتور، نرم‌افزار کال سنتر، تبدیل گفتار به متن فارسی، تحلیل احساس مشتری.
- **راهنما (قصد آموزشی/فنی):** نصب ماژول FreePBX، کلید API صداسنج، کدهای خطا (`SS-…`)، ضبط مکالمات الستیکس و ایزابل.
- **تست رایگان و ثبت‌نام (قصد اقدام):** تست رایگان تحلیل مکالمه، تبدیل فایل صوتی به متن فارسی، قیمت و پلن‌های تحلیل مکالمات.
- **درباره/تماس/قوانین:** عبارت‌های برند و اعتماد (درباره صداسنج، تماس با صداسنج، حریم خصوصی و امنیت داده).

هر صفحه یک `h1` دارد؛ کلیدواژهٔ اصلی باید در `title`، `description` و `h1` همان صفحه باشد و بین صفحات تکرار نشود.
`<meta name="keywords">` را گوگل نادیده می‌گیرد؛ برای موتورهای دیگر و مستندسازی نگه داشته شده است.

## محدودیت‌ها و کارهای باقی‌مانده

- تصویر اشتراک‌گذاری `public/og-image.jpg` (۱۲۰۰×۶۳۰) برش همان تصویر قهرمان است؛ تصویر طراحی‌شده را جایگزین کنید.
- فاویکون `public/favicon.webp` (شکل موج صوتی) موقت است؛ در صورت داشتن طرح نهایی جایگزینش کنید.
- محتوای متن صفحات «درباره»، «تماس» و حقوقی از پنل ادمین ویرایش می‌شود و به‌صورت کلاینتی رندر می‌شود؛ گوگل آن را اجرا می‌کند، اما خزنده‌های بدون JS فقط head و بخش `noscript` را می‌بینند. SSR کامل در این تغییر انجام نشده است.
- پس از استقرار: ثبت دامنه در Google Search Console و Bing Webmaster Tools، ارسال `sitemap.xml`، بررسی با Rich Results Test.
