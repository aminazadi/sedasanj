# رفع خطای نصب وابستگی‌های تصویر تحلیل احساسات

## نشانه‌ها

ساخت `worker-emotion` پس از دانلود موفق PyTorch با پیام `No matching distribution found` برای `setuptools` یا وابستگی‌های دیگر متوقف می‌شود.

## علت

میرور انتخاب‌شده ممکن است بسته یا نسخهٔ موردنیاز را نداشته باشد. دانلود موفق PyTorch به معنی کامل بودن میرور بسته‌های عمومی نیست.

## رفع

1. آخرین تغییرات پروژه را دریافت کنید.
2. از مسیر `sedasanj/deploy` دستور زیر را اجرا کنید. نیازی به حذف کش نیست:

```bash
docker compose build worker-emotion
docker compose up -d worker-emotion
```

3. نصب ابزارهای ساخت و وابستگی‌های فایل محلی PyTorch اکنون میرور اصلی و سپس میرورهای جایگزین را به ترتیب امتحان می‌کند. اگر همه شکست بخورند، کد ساخت `SS-DEP-0001` نمایش داده می‌شود؛ دسترسی شبکه و وجود نسخهٔ بسته را بررسی کنید و آرگومان‌های ساخت `PIP_INDEX_URL` و `PIP_FALLBACK_INDEX_URLS` را به میرورهای کامل و در دسترس تنظیم کنید.

## تأیید

ساخت باید با موفقیت تمام شود. سپس با `docker compose ps worker-emotion` وضعیت سرویس را بررسی کنید.

## پیشگیری

میرورهای جایگزین را در تنظیمات ساخت حفظ کنید و نسخه‌های پین‌شده را فقط پس از بررسی سازگاری تغییر دهید. کد بالا مخصوص خطای ابزار ساخت است و کد خطای API یا ماژول FreePBX نیست.
