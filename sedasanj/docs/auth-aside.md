# پنل تزئینی صفحهٔ ورود و ثبت‌نام

از پنل ادمین، بخش **صفحه‌های سایت ← پنل صفحه ورود و ثبت‌نام** مدیریت می‌شود
(`PUT /v1/admin/site-pages/auth_aside`، ذخیره در `platform_settings`).

## رفتار برای بازدیدکننده

- پنل سبز سمت چپ (هم‌رنگ سایدبار پنل‌ها) پیام‌ها را یکی‌یکی تایپ می‌کند، بعد از مکث پاک می‌کند و
  پیام بعدی را می‌نویسد. با یک پیام، همان پیام ثابت می‌ماند.
- دکمهٔ فراخوان (CTA) پیام فقط بعد از پایان تایپ دیده می‌شود. با رفتن ماوس یا فوکوس روی پنل، چرخش متوقف می‌شود.
- با `prefers-reduced-motion` متن بدون افکت تایپ و فقط با مکث عوض می‌شود. روی صفحهٔ کوچک (زیر ۹۰۰px) پنل نمایش داده نمی‌شود.

## تنظیمات

| فیلد | توضیح |
| --- | --- |
| پیام‌ها | ۱ تا ۸ مورد؛ متن تا ۲۰۰ نویسه |
| متن و پیوند دکمه | اختیاری، ولی باید با هم پر شوند (`/مسیر`، `https://`، `tel:` یا `mailto:`) |
| سرعت تایپ | ۲۰ تا ۲۰۰ میلی‌ثانیه برای هر حرف (پیش‌فرض ۵۵) |
| مکث | ۱ تا ۳۰ ثانیه (پیش‌فرض ۴) |

## خطاها

ذخیرهٔ نامعتبر با کد `invalid_request` و نام فیلدهای ایراددار رد می‌شود؛ فیلدها را اصلاح و دوباره ذخیره کنید.
اگر محتوای ذخیره‌شده خراب باشد یا بارگذاری نشود، پیام پیش‌فرض نمایش داده می‌شود.
