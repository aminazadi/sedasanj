# بروزرسانی جدول تماس‌ها

در صفحهٔ «تماس‌ها»، دکمهٔ «بروزرسانی» بالای جدول، اطلاعات تماس‌ها را دوباره دریافت می‌کند. فقط بخش جدول بروزرسانی می‌شود؛ فیلترهای اعمال‌شده، جست‌وجو، تعداد ردیف‌ها و صفحهٔ فعلی حفظ می‌شوند. اگر صفحهٔ فعلی دیگر وجود نداشته باشد، آخرین صفحهٔ موجود نمایش داده می‌شود.

هنگام دریافت اطلاعات، دکمه غیرفعال و وضعیت «در حال بروزرسانی…» نمایش داده می‌شود. پس از پایان درخواست، اطلاعات جدید در جدول نمایش داده می‌شوند.

اگر دریافت اطلاعات ناموفق بود، پیام خطا بالای جدول نمایش داده می‌شود. اتصال اینترنت را بررسی کنید و دوباره «بروزرسانی» را بزنید. این قابلیت از همان مسیر دریافت تماس‌ها و خطاهای موجود آن استفاده می‌کند.
