# پوش Android جلسه‌نگار

## پروژه‌های Firebase و ساخت اپ

۱. برای انتشار و توسعه دو پروژهٔ Firebase جدا بسازید. در پروژهٔ انتشار برنامهٔ
`app.jalasenegar.jalase_negar` و در پروژهٔ توسعه برنامهٔ
`app.jalasenegar.jalase_negar.dev` را ثبت کنید. سه کانال Android در انتشار شناسهٔ
بستهٔ مشترک دارند.

۲. یک فایل JSON خارج از مخزن با مقادیر عمومی تنظیمات Android همان پروژه بسازید.
`PUSH_ORIGIN` نشانی HTTPS پنلی است که API و worker پوش آن به همان پروژه متصل‌اند.

```json
{
  "PUSH_FIREBASE_APP_ID": "<mobilesdk_app_id>",
  "PUSH_FIREBASE_API_KEY": "<android_public_api_key>",
  "PUSH_FIREBASE_SENDER_ID": "<project_number>",
  "PUSH_FIREBASE_PROJECT": "<project_id>",
  "PUSH_ORIGIN": "https://api.sedasanj.ir"
}
```

۳. برای ساخت انتشار در هر سه کانال، متغیر `JALASE_PUSH_CONFIG` را روی مسیر فایل
انتشار تنظیم کنید و `scripts/build-jalase-negar-release.sh android` را اجرا کنید.
برای ساخت توسعه از فایل پروژهٔ توسعه و نشانی HTTPS آزمایشی استفاده کنید.

```bash
flutter run --flavor direct --dart-define-from-file=/path/to/firebase-dev.json
```

## تنظیم و آزمایش ارسال

- پس از اجرای migration، API، پنل ادمین و `worker_notify` را با هم به‌روز کنید.
  کلید رمزنگاری اسرار پلتفرم باید برای API و worker مشترک و پایدار باشد.
- در پنل اصلی به «پوش جلسه‌نگار ← تنظیمات» بروید. پروژه و JSON حساب سرویس دارای
  دسترسی ارسال FCM را وارد کنید. اعتبارنامهٔ حساب سرویس را فقط در تنظیمات سرور
  وارد کنید. آزمون اتصال از حالت اعتبارسنجی Firebase استفاده می‌کند.
- اپ جدید را روی گوشی دارای Google Play Services باز کنید، مجوز اعلان را بدهید و
  ظاهرشدن آن را در تب «دستگاه‌ها» بررسی کنید. قبل از ارسال سراسری، یک ارسال آزمایشی
  انجام دهید و دریافت و لمس اعلان را در پیش‌زمینه، پس‌زمینه و اجرای سرد بررسی کنید.
- نتیجهٔ «پذیرفته‌شده توسط Firebase» وضعیت پذیرش سرویس است. برای تأیید نمایش، گوشی
  آزمایشی را بررسی کنید. اپ آخرین دادهٔ سفارشی دریافت‌شده را در فضای امن محلی نگه
  می‌دارد. حالت بی‌صدا با اولویت عادی ارسال می‌شود.
- برای توقف ارسال، کمپین را در تاریخچه لغو کنید یا کلید ارسال را در تنظیمات خاموش
  کنید. اعتبار هر پیام از زمان برنامه‌ریزی‌شده محاسبه می‌شود.
