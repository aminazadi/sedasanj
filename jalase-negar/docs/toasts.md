# پیام‌های کوتاه جلسه‌نگار

پیام‌هایی مانند تأیید کپی متن، خطای ضبط و حذف جلسه زیر هدر نمایش داده می‌شوند. برای کنار زدن پیام، آن را به بالا بکشید.

اگر جلسه‌ای را با کشیدن کارت حذف کردید، تا وقتی پیام «جلسه حذف شد» روی صفحه است می‌توانید «بازگردانی» را بزنید. برای بررسی، بازگشت کارت به فهرست را ببینید.
