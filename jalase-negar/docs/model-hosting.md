# دریافت مدل‌های جلسه‌نگار

مدل‌ها از نشانی `https://sedasanj.ir/jalase-negar-models/v1/` دریافت می‌شوند. در استقرار Compose، سرویس `jalase-negar-models-init` فایل‌های موجود را نگه می‌دارد و فایل‌های غایب را یک بار از منابع اصلی دریافت می‌کند. پوشهٔ پیش‌فرض `jalase-negar-models` در ریشهٔ مخزن است؛ برای تغییر مسیر روی سرور، مقدار `JALASE_NEGAR_MODELS_DIR` را در تنظیمات استقرار تعیین کنید. این پوشه باید فضای کافی و دسترسی نوشتن داشته باشد و نباید در Git ثبت شود. فرانت فایل‌ها را فقط با دسترسی خواندن می‌بیند.

اگر خطای `JN-MDL-0001` ظاهر شد، اتصال اینترنت و فضای دیسک سرور را بررسی کنید، گزارش سرویس `jalase-negar-models-init` را ببینید و سرویس را دوباره اجرا کنید. سپس در برنامه دانلود را دوباره آغاز کنید. برای اطمینان، یکی از نشانی‌های کاتالوگ را با درخواست HTTP بررسی کنید؛ پاسخ باید فایل مدل باشد. فایل‌ها را فقط از منابع معتبر جایگزین کنید و نسخهٔ مسیر را هنگام تغییر وزن‌ها افزایش دهید تا نصب‌ها و دانلودهای نیمه‌تمام ناسازگار نشوند.
